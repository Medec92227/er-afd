# Documentación de la entrega

Los PDF conservan el formato universitario y las portadas proporcionadas por los integrantes:

| Archivo | Contenido |
| --- | --- |
| `Reporte_tecnico.pdf` | 9 páginas: auditoría, algoritmos, diagramas, matrices, decisiones y referencias. |
| `Manual_usuario.pdf` | 5 páginas: instalación, ejecución, códigos de retorno y consultas. |
| `Casos_de_prueba.pdf` | 13 páginas: pruebas adicionales, metodología, métricas y anexo con las seis capturas reales de Ubuntu. |

Los originales PNG completos y sus registros están en `evidencias/linux/20261102T180611Z/`. Los encuadres del anexo amplían la terminal para facilitar la lectura; no sustituyen ni modifican los originales.

La VM Ubuntu 26.04.1 LTS x86_64, con Python 3.14.4 y GNU Make 4.4.1, completó 16 comprobaciones, 39 pruebas unitarias, 1499 casos con oráculo y 20306 comparaciones AFND/AFD sin fallos. Los registros históricos de Windows permanecen separados. El estado de GitHub Actions se consulta en el repositorio.

Material de apoyo: `PASOS_PRUEBAS_UBUNTU.md`, `PRUEBAS_LINUX.md`, `CUMPLIMIENTO.md`, `DEFENSA.md`, `../README.md` y `../FUENTES.md`.
